# 갯벌로그

부산의 갯벌과 바닷가에서 생물을 사진으로 관찰하며, 나만의 해양생물 도감을 쌓는 모바일 중심 웹앱입니다. 핵심 문구는 **“10종으로 시작하고, 발견한 만큼 나만의 도감이 넓어진다.”** 입니다.

## 실행

```bash
npm install
npm run dev
npm run build
```

## 핵심 기능

- 로그인, 회원가입(데모), 브라우저 내 체험 모드
- 10종 기본 도감과 발견 진행률
- 모바일 카메라/갤러리 사진 선택(최대 3장), 품질 안내
- 확정하지 않는 데모 판별 흐름과 사용자 후보 확인
- 기본 도감 등록, 개인 발견 도감, 미확인 생물함, 기록 삭제
- 사용자별 localStorage 데이터 분리와 내보내기

## 데이터와 AI 교체

- 프로젝트 이름은 `src/config/app.ts`에서 바꿉니다.
- 기본 10종은 `src/data/baseSpecies.ts`만 수정하면 전체 화면에 반영됩니다.
- 현재 기본 10종은 임시 데이터다. 실제 탐방 지역에서 발견 가능성이 높은 종이 확정되면 `src/data/baseSpecies.ts`의 데이터만 교체하면 된다.
- AI 연결은 `src/lib/identification/SpeciesIdentifier.ts` 인터페이스와 `ApiSpeciesIdentifier.ts`를 구현해 교체합니다. 현재는 **데모 판별 모드**이며, AI 결과를 사실로 확정하지 않습니다.

## 개인정보·위치

기록은 브라우저에 저장되며 공개 범위의 기본값은 비공개입니다. 위치는 넓은 지역명만 다루도록 설계되어 있고 민감 생물의 정확한 위치를 표시하지 않습니다. 실제 서비스 전에는 IndexedDB 기반 사진 저장과 검증된 외부 인증/데이터베이스 서비스를 연결하세요.
